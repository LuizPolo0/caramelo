Caramelo do Bem

Plataforma colaborativa para reportar, mapear e coordenar o resgate de cães em situação de rua.

📦 Código-fonte 🚀 Acessar aplicação

📋 Sobre o projeto

Caramelo do Bem conecta quem encontra um cão em situação de rua a voluntários, ONGs e veterinários dispostos a ajudar. Qualquer pessoa pode reportar uma ocorrência com foto, localização e nível de urgência; a ocorrência aparece no mapa da cidade e voluntários podem se candidatar para o resgate, abrigo temporário ou atendimento veterinário.

Next.js 14 (App Router) React 18 TypeScript Supabase (Auth + Postgres) Tailwind CSS Leaflet / react-leaflet Radix UI

👥 Papéis de usuário

🙋 Reportador Registra ocorrências de cães encontrados na rua, com foto, endereço e urgência.
🤝 Voluntário Visualiza o mapa de ocorrências e se candidata para resgate ou lar temporário.
🏠 ONG / Abrigo Acompanha ocorrências e resgates em um painel dedicado.
🩺 Veterinário Registra atendimentos veterinários vinculados a uma ocorrência.

✨ Funcionalidades

  • 🔐 Cadastro e login (e-mail/senha e Google)
  • 📢 Reportar ocorrência com foto e geolocalização
  • 🗺️ Mapa interativo de ocorrências ativas
  • 🐕 Detalhe da ocorrência com histórico de resgates
  • 🤲 Confirmação de resgate, lar temporário ou atendimento vet.
  • 📊 Painel dedicado para ONGs e veterinários
  • 👤 Perfil com estatísticas de ocorrências e resgates

🏗️ Arquitetura

Aplicação client-first: o Next.js serve as páginas e todo acesso a dados/autenticação é feito diretamente pelo navegador via Supabase, usando apenas a chave pública (anon key).

🗃️ Modelo de dados

Baseado no schema em scriptBancoDeDadosSupabase.sql, aplicado no Postgres do Supabase.

erDiagram
  PROFILES {
    uuid id PK "= auth.users.id"
    text nome
    text telefone
    text role "reporter | volunteer | ong | vet"
    text avatar_url
    text bairro
    timestamptz created_at
  }
  OCORRENCIAS {
    uuid id PK
    uuid user_id FK
    text titulo
    text descricao
    text endereco
    text bairro
    numeric lat
    numeric lng
    text_array situacao
    text porte "Pequeno | Médio | Grande"
    text urgencia "Estável | Atenção | Urgente"
    text status "ativo | em_resgate | resgatado | arquivado"
    text foto_url
    timestamptz created_at
    timestamptz updated_at
  }
  RESGATES {
    uuid id PK
    uuid ocorrencia_id FK
    uuid voluntario_id FK
    text tipo "resgate | lar_temp | veterinario"
    text status "confirmado | em_andamento | concluido | cancelado"
    text observacao
    timestamptz created_at
  }
  MENSAGENS {
    uuid id PK
    uuid ocorrencia_id FK
    uuid user_id FK
    text texto
    text tipo "texto | sistema | foto"
    timestamptz created_at
  }

🔄 Fluxo principal de uso

sequenceDiagram
    actor R as Reportador
    participant App as Caramelo do Bem
    participant SB as Supabase
    actor V as Voluntário / ONG / Vet

    R->>App: Login / Cadastro
    App->>SB: auth.signUp / signIn
    SB-->>App: sessão + perfil

    R->>App: Reportar ocorrência (foto, local, urgência)
    App->>SB: insert em ocorrencias
    SB-->>App: ocorrência criada (status: ativo)

    V->>App: Abrir mapa de ocorrências
    App->>SB: select ocorrencias (públicas)
    SB-->>App: lista de ocorrências ativas

    V->>App: Confirmar resgate / lar temp. / atendimento vet.
    App->>SB: insert em resgates
    SB-->>App: resgate registrado
    App->>SB: update ocorrencias.status (em_resgate / resgatado)
